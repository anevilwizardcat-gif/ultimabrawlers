<AIの特徴>

・「完全近距離型タイプ」 
　とにかく近距離に持ち込まないと話にならないので攻めてくる。
　ダッシュ小ジャンプができないため、奇襲しにくい面もありかなり苦戦する。
　(ダッシュからの小ジャンプ操作はハイジャンプに移行する。)
　攻撃判定が短いのが多いため、リーチ差によっては何もできないまま沈む。
　通常攻撃はリーチの長い「しゃがみ強パンチ」と発生の早い「しゃがみ弱パンチ」で攻める。
　火力不足な箇所が多いので、コンボをしまくってチビチビ減らすしかない。


・「切り返しやカウンターでのチャンス」
　1Fで攻撃可能な１ゲージ技の「ファイナルヘブン」や「メテオストライク」
　切り返しには、「ドルフィンブロウ」でもいいが攻撃範囲が異常に狭いため狙いにくい。
　空中では、一番攻撃距離のあるジャンプ強キックで攻めるが、16Fとかなり遅いため牽制向き。
　ジャンプ弱キックは、攻撃範囲が上に長いので何気に対空に使えたりする。　


・「ゲージコンボで一気に勝負を仕掛けたいが火力が足りない」 
　2ゲージあれば「超水面蹴り」→「ファイナルヘブン」というコンボが可能だが、
　コンボ補正＋火力不足が備わって、1/5程度しかダメージを与えられない。
　「高速ドルフィンブロウ」→「ファイナルヘブン」の方が倍くらい強かったりする。
　3ゲージコンボ技の「リミットブレイク」は、3ゲージとは思えない火力不足で泣ける。
　しかも、乱舞中は無敵でもないため、タッグ戦では容易に使えないのが難点。

　
・「巨乳より貧乳の方が好きです」
　「前後転」は技の終わりまで「投げ」以外は無敵であるが、
　有り余る巨乳のおかげで転がった後は胸が揺れる。
　それ故に、操作できるまで時間が掛かるので回避しても投げ返される確率が高い。

＜AIレベルの変更＞

AIレベルの変更、及び随時AI起動スイッチのON/OFFの設定ができます。
レベルの強さは最後の方に書いてありますので参考程度にどうぞ。
随時AI起動スイッチをONにすると、自分では一切操作できませんのでご了承ください。
AIを通常より素早く起動させたい場合は、同フォルダ内にある
「随時AIスイッチ以外で早くAI起動させたい場合.txt」を参照してください。


[State -3, AI]
type = varset
triggerAll = !var(59)
triggerAll = RoundState = [1,2]
trigger1 = Command = "AI0"
～～～(以下省略)～～～
trigger50 = Command = "AI49"
trigger51 = Command = "AI50"
trigger52 = NumHelPer(40000) > 0 && RoundState = 2
trigger52 = HelPer(40000),Var(59) > 0
;trigger53 = 1         ; ←AI起動スイッチ 
;                        常にAI操作したい場合は「trigger53」の後ろの
;                       「;」を消去してください

V = 59
Value = 5              ; ←ここの値を変えることでAIレベルを設定します。
;                        1～5まで設定可能。
;                       

説明のとおりに「Value」の値を1～5に変更してください。
初期設定は「5」になっています。
