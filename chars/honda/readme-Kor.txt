  조작법
  ------

    기본 조작
    ---------
      D - 아래
      F - 앞
      U - 위
      B - 뒤
      x - 버튼 X (약펀치)
      y - 버튼 Y (중펀치)
      z - 버튼 Z (강펀치)
      a - 버튼 A (약킥)
      b - 버튼 B (중킥)
      c - 버튼 C (강킥)

    기본동작
    --------
      U              - 점프
      UF             - 전방점프
      F              - 전방걷기
      DF             - 앉기
      D              - 앉기
      DB             - 앉기 또는 하단가드
      B              - 후방걷기 또는 상단가드
      UB             - 후방점프
      F, F           - 전방대시
      B, B           - 후방대시
      x+y/x+z/y+z/a+b/b+c/a+c             - 낙법 (추락시)
       
    기본 상단공격
    -------------
      x              - 약펀치
      y              - 중펀치
      z              - 강펀치
      a              - 약킥
      b              - 중킥
      c              - 강킥
      F + b         - 무릎차기
      F + c         - 때려차기 

    기본 하단공격
    -------------
      x              - 약펀치
      y              - 중펀치
      z              - 강펀치
      a              - 약킥
      b              - 중킥
      c              - 강킥
      DF + z       - 하단 후리기

    기본 공중공격
    -------------
      x              - 약펀치
      y              - 중펀치
      z              - 강펀치
      a              - 약킥
      b              - 중킥
      c              - 강킥

    잡기
    ------
      F/B + x+y/y+z/x+z                  - 펀치 잡기
      F/B + a+b/b+c/a+c                  - 킥 잡기
      (in the air) F/B + x+y/y+z/x+z  - 공중 잡기

    필살기
    ------
      (가드 중) F + 같은 위력의 PK     - 제로 카운터

    [노멀 그루브]
      B (1초동안 축적) F + P              - 슈퍼 박치기

      F, D, DF + K                              - 슈퍼 백관락 떨어뜨리기  

      레버 1회전 + P                          - 대은행 던지기  

      P 연타                                      - 백열장    

    [G-그루브]
      (공중에서) D + M.K                    - 천마공인각

      (공중에서) D, DF, F + P              - 참공박치기

      B (1초동안 축적) F + P               - 호 박치기

      F, D, DF + P                             - 승 박치기

      레버 1회전 + P                         - 멸살 대은행 던지기  

      P 연타                                     - 호 백열장  

      F, D, DF + 3P 또는 3K                - 아수라섬공
      B, D, DB + 3P 또는 3K
 
      F, D, DF + K                             - HyakkiShuu
     
     └ 무입력                                 - HyakkiGouZan
     
     └ P                                         - HyakkiGouShou

     └ K                                         - HyakkiGouSen

     └ (상대방 근처)F 또는 B + P     - HyakkiGouSai

     └ (상대방 근처)F 또는 B + K     - HyakkiGouTsui

    --------
