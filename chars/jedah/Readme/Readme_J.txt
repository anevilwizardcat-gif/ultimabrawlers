ジェダ＝ドーマ
最終更新日時：2016/2/14　完成度98.9%

アーケードモードでラスボスとして登場するのにも関わらず、セイヴァーの主人公です。
空中からの多彩なラッシュがありながらしゃがみ強Kでダウンがしない唯一のキャラのため起き攻めに以降しづらい面があります。

原作では特殊な体力ゲージ（回復可能と不能ダメージの２種類がある）だったため、回復不能ダメージの部分+αを基本ダメージとしています（CFJ並みの攻撃力(CVS2より一回り高い程度)）。要は、ハンター２のアレンジバージョンの攻撃力です。
ただし、回復可能ダメージのみの技は回復可能ダメージの約半分としています。

ダメージレベル2,TURBO3(小数点の誤差あり),バットマーク*2を基準にしてあります。
セイヴァー系以外の通常技の回復可能分ダメージ増加量は"Impact_Damage_System_J.txt"を参照してください。

ラウンド開始時に方向ボタンの左右でセイヴァー２・カプコンファイティングジャム性能に変更できます。
また、方向ボタンの上下でインパクトダメージゲージシステムの変更ができます。

option.cnsを変更することで音声、インパクトダメージゲージシステム、AI Levelの変更ができます。

インパクトダメージゲージシステムは仕様上一部のキャラには対応していません。

勝利ポーズはKO後攻撃ボタンいずれかを押したままにすることで対応した勝利ポーズに変化します。
弱Kボタンで出てくる勝利ポーズはEXエディションのものです。

このキャラの大きさは原作に合わせております(参考：CPS2の実機が384×224ドット)が、AI(X方向のみ)、飛び道具の発射位置、ヒットバックなどはキャラ幅に合わせてありますので、お好みで変更しても特別な問題が起きないようにしてあります。

サングェ＝パッサーレの輸血されるモーションは以下のキャラに対応してあります。
Vampire Savior,Vampire Savior2,Vampire Hunter2の全てのキャラ（Deeを除く）

プロヴァ＝ディ＝セルヴォの契約書は以下のキャラに対応しています。
Vampire Savior,Vampire Savior2,Vampire Hunter2の全キャラ
Capcom Fighting Jamの全キャラ
ストリートファイターIIIの一部のキャラ（トゥエルヴ、ネクロ、ヒューゴ、ギル）
サムライスピリッツ天下一剣客伝の一部のキャラ（天草、シャルロット、いろは）
対応キャラKO時に契約書が画面内に残ります。

・AI
AIレベルは3段階（初級者、中級者、上級者。デフォルトは上級者）から選択できます。
違いは、コンボ精度や立ち回りです。
ＬＶ．３上級者になると、永久コンボしだします。お気をつけください（途中で中断したり、ミスしたりしますが）。

AIの反応速度を搭載しました。Lv毎に変わります。格闘ゲームでは、12Fが限界の反応速度といわれています。ただし、安定して反応できるのは20F程度です。それ以下では上級者でもフェイントに反応したりしてしまうので。反応速度を鍛えていない方なら、24～30Fぐらいになると思います。
Beginner:24F～、Advanced:20F～、Expert:16F～
Expertと言っても原作の上級者並みの動きにはなりません。というのも、キャラ対策や読みなどがAIには厳しいからです。中級者ぐらいを想定していただけたらと思います。

勝利ポーズは選択したカラーに対応したボタンを優先します。
例えば、弱Ｋカラーの場合弱Ｋカラーの勝利ポーズが出てくる確率が高くなります。

・バグ・仕様など
アドバンシングガード（通称アドバ）はスライド入力だと比較的楽に出せます。ボタン連打ではほとんど出せません。
上記は原作での話で、MUGEN上ではアドバンシングガードが原作通りに出来ません。
MUGEN上ではボタン入力の精度が1/60Fでないようで、ボタンの入力回数が上手く認識されません。同じ入力方法でエミュレーター上ではボタン入力が３～５回はカウントされたのですが、MUGEN上ではなぜか、1～２回しかカウントされませんので。
あまりにもカウントされないので、２つ同時押しで２回カウントするようにしてあります。対処法があればご連絡ください。

一般的な速度ターボ3にしてありますが、1Fの速度が前述の通り違うため、フレーム数は完全に原作どおりには出来ません。
