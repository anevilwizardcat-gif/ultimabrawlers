通常技

弱攻撃　xボタン
中攻撃　yボタン
強攻撃　zボタン
スタンドボタン　aボタン
x + y + z　bボタン
;----------------------------------------------------------------------------
特殊技

小ジャンプ　すばやく U
大ジャンプ　すばやく D, U
回り込み　x + y + z
アドバンシングガード　ガード中に x + y + z
ガードキャンセル攻撃　ガード中に F, D, DF ＋ x/y/z
ダウン回避　攻撃ボタン二つ同時押し
スタンド発動攻撃　D, DF, F ＋ a
;----------------------------------------------------------------------------
必殺技（本体モード時）

山吹色の波紋疾走　　F, D, DF ＋ x/y/z
波紋のビート　　方向キー一回転 ＋ x/y/z
策士の業　　D, DB, B ＋ x/y/z
青緑波紋疾走　　D, DF, F ＋ x/y/z
;----------------------------------------------------------------------------
必殺技（スタンドモード時）

山吹色の波紋疾走　　F, D, DF ＋ x/y/z
波紋のビート　　方向キー一回転 ＋ x/y/z
策士の業　　D, DB, B ＋ x/y/z
ハーミットウェブ　　D, DF, F ＋ x/y/z
;----------------------------------------------------------------------------
スーパーコンボ

師の教え　　D, DF, F, 攻撃ボタン二つ同時押し
波紋疾走　　方向キー二回転 ＋ x/y/z　or　F, DF, D, DB, B + 攻撃ボタン二つ同時押し
タンデムアタック　　D, DB, B ＋ a

補足（バグ）

・原寸大のドットで表示するには、jotaro.cnsの[size]にある
  [Size]
  xscale = 0.83
  yscale = 1.07
  を
  [Size]
  xscale = 1
  yscale = 1
  に、ground.frontとair.frontを22にして下さい。

・2ラウンド目以降にstartボタンを押すとスタンドon/off切り替えが出来ます。

・WIN版のみチームモード交替時にスタンドゲージが0になる時がある
