セイヴァー１、２

通常投げ				至近距離で4か6+中Por強P(CFJ弱P+弱K)
空中投げ				至近距離で8以外の方向ボタン+中Por強P(CFJなし)
ダッシュ、バックダッシュ	前または後ろの方向ボタン２回押し
チェーンコンボ			弱→中→強、同じ強さのパンチ→キックという順序で通常技がキャンセル可能。
アドバンシングガード		ガード中に攻撃ボタン連打(CFJなし)
ガードキャンセル			ガード中に特定の必殺技のコマンド入力
ダークフォース			同じ強さのパンチ、キック同時押し(CFJなし)
移動起き上がり			ダウン時に4か6押しっぱなし
追い打ち攻撃			相手ダウン時に8要素+攻撃
