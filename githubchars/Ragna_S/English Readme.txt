DO NOT play this character on a 640 X 480 screen. It is meant to be played on a
1280 X 720 screen or else you will have problems.

You MUST and I repeat MUST have your mugen config file like this for the screen.

GameWidth = 1280
GameHeight = 720

The character WILL NOT WORK properly if you play mugen using any width or height
LOWER than this setting.

DO NOT CHANGE THE LOCALCOORD AT ALL!

This character WILL NOT work in Winmugen! It's only for Mugen 1.1.

This Character was not made for 2v2 Simul mode!

Mode select

During the intro you can select a mode for Ragna

"Attack Up" Press up to select. Increases attack power but you take more damage when hit. 

"Defense Up" Press down to select. Increases defense but decreases attack.

"Normal" Press back to select. Balances stats out.

"Life" Press Forward to select. Greatly increases attack but you automaticly die if life. 
is 300 or less.
