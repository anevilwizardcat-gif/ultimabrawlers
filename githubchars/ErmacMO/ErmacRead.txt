z = z button

--------------

a - Low Punch
b - Low Kick

D+y - Ducking High Kick
D+a - Ducking Punch
D+b - Ducking Low Kick
B+y - RoundHouse Kick
B+b - Sweep Kick
F+a or B+a - Throw (Up close)
z - Run
c - Block

COMMENTS
-----------------------
- If you try do the Decap Uppercut, and the opponent doesn't have the Obreck
  fatality frames (See Sframes.txt) then you'll get an error sound and 
  nothing will happen.
- Sadly, Opponents like Onslaught and certain others cannot be tele-slammed.
- You have to win a round before you can do a fatality in single player
  mode. In turns you can do it every round, since you fight a different 
  opponent each round. Fatalities can be quite glitchy in simul mode so
  I don't recommend using them in simul mode.
- mkninja.cns is a universal file for all my Mk Ninjas. You can take the
  mkninja.cns file from any future release of mine and copy over Ermac's.
  to gain any bugfixes in that file I made since this release.
- You can pick a win pose by holding start & a direction when you win.
- Fatalities aren't available in Simul mode. 
- Hitoverride support is unavailable in Simul mode.

TO ADD A HOLD BACK BLOCK:
----------------------------------
Open up AI.cns with a text editor find the following lines and place ;'s in
front of them:

[State -2, NoGuard1]
type = AssertSpecial
trigger1 = var(21) != 1
trigger1 = 1
flag = nostandguard

[State -2, NoGuard2]
type = AssertSpecial
trigger1 = var(21) != 1
trigger1 = 1
flag = nocrouchguard

[State -2, NoGuard3]
type = AssertSpecial
trigger1 = 1
flag = noairguard

TO MAKE HIM WORK FOR DOSMUGEN
-----------------------------------------
Take the files out of his "DOSMugen" folder and move them to his other 
folders, overwriting the windows version files of the same name.

The dos files are of a much older older build and have bugs the windows one don't.
Don't say I didn't warn you.

Due to WinMugen changing the basic block scripts dramticly, there was no
way to make a single version of him that works for both the Dos and 
Windows version.
